## Avant de commencer

**Marketplace → Programmes athlètes** (`/programming/athletes`) regroupe les programmes de coaching que tu vends à tes athlètes. Les formules d'accès à la salle (abonnement, Drop-in, carnet, essai) et les codes promo vivent désormais dans **Formules** — voir « Formules d'accès à la salle ». Pour encaisser en ligne, les paiements doivent être activés dans **Réglages → Paiements**.

## Étapes

1. Ouvre **Marketplace → Programmes athlètes**. Si la page t'invite à **activer les paiements pour vendre tes programmes**, fais-le depuis **Réglages → Paiements** : sans cela, tu ne peux qu'assigner des accès à la main. <Screenshot src="/tutorials/programmes-athletes-vente/1.png" alt="Onglet Programmes athlètes de Marketplace" />
2. Clique **Créer un programme** : la modale **Nouveau programme** demande un **Titre**, une **Description** et un **Prix (€)**. <Screenshot src="/tutorials/programmes-athletes-vente/2.png" alt="Modale Nouveau programme : titre, description, prix, type de programme, durée" />
3. Choisis le **Type de programme** : **Programme fixe** (« Durée définie (6, 8, 12 sem.) »), qui ouvre **Durée (semaines)** et **Jours / semaine**, ou **Ongoing** (« Programme continu »), sans date de fin. Ces champs sont dans la même modale qu'à l'étape 2.
4. Coche **Actif (visible pour les athlètes)** quand l'offre est prête, puis **Créer le programme** : c'est cette case qui la fait apparaître sur ta page publique.
5. Utilise **Donner l'accès à un membre** sur la fiche du programme pour offrir un accès sans paiement en ligne. Les **codes promo** se gèrent dans **Formules**.

## Erreurs fréquentes

- **L'offre n'apparaît pas côté athlète.** Elle n'est pas cochée **Actif (visible pour les athlètes)** → coche la case et recharge la page publique.
- **Le paiement échoue ou le bouton manque.** Les paiements ne sont pas activés pour la box → termine la configuration dans **Réglages → Paiements**, puis réessaie.
- **Un code promo reste sans effet.** Il est expiré, ou sa durée de remise est terminée → vérifie la date d'expiration dans **Formules → Codes promo**.
- **Un membre a payé mais n'a pas le contenu.** Le programme vendu n'a pas encore de séances → remplis-le, ou donne-lui l'accès à un programme complet.
