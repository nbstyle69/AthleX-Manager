## Avant de commencer

Une **semaine type** est une copie figée d'une semaine du Whiteboard, rangée dans ta box pour être reposée quand tu veux. Elle est interne : elle ne se vend pas et ne s'expose à personne.

## Étapes

1. Sur le Whiteboard, affiche la semaine que tu veux garder comme modèle. <Screenshot src="/tutorials/semaines-types/3.png" alt="Whiteboard de la semaine à enregistrer comme modèle" />
2. Clique **Enregistrer comme semaine type**, donne-lui un **Nom** parlant (par exemple « Semaine Hybrid – volume ») — ou choisis une semaine type à écraser —, puis clique **Enregistrer**. <Screenshot src="/tutorials/semaines-types/1.png" alt="Fenêtre Enregistrer comme semaine type avec un nom saisi" />
3. Pour la reposer, place-toi sur la semaine cible et ouvre **Programmation** : la modale liste **Mes semaines types** et les **Programmations Marketplace** auxquelles la box est abonnée. <Screenshot src="/tutorials/semaines-types/2.png" alt="Fenêtre Programmation avec une semaine type sélectionnée et Toute la box choisi" />
4. Choisis la semaine type, la **Semaine cible**, puis l'audience dans **Qui voit ces WOD ?** — sans ce choix, l'application n'est pas possible.
5. Clique **Appliquer** (ou **Remplacer les WOD vierges** si la semaine cible porte déjà des WOD). Les WOD sont recopiés sur les jours de la semaine cible ; ceux qui portent déjà un score ou une complétion ne sont pas touchés par un remplacement.

## Erreurs fréquentes

- **« J'ai enregistré une semaine type, mais mon offre Marketplace est toujours vide. »** « Enregistrer comme semaine type » n'alimente pas une offre : c'est **Copier vers une offre** qui recopie la semaine dans une semaine d'offre → utilise ce bouton (gérant) depuis le Whiteboard, ou l'icône de copie de la semaine type dans **Programmation**.
- **La modale Programmation est vide.** Aucune semaine type n'existe et la box n'est abonnée à aucune programmation → enregistre une semaine, ou abonne la box dans Entraînement → Marketplace (gérant).
- **Les WODs posés ne sont visibles par personne.** L'audience choisie à l'application était « personne encore » → rouvre les séances et fixe leur audience.
- **Supprimer une semaine type a-t-il effacé mes semaines ?** Non : les semaines déjà posées sur le Whiteboard restent, seul le modèle disparaît.
