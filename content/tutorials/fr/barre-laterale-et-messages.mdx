## Avant de commencer

La barre latérale, à gauche (bouton « Ouvrir le menu » sur téléphone), mène à tous tes écrans. **Messages** (Animation → Messages) réunit les conversations de tes groupes. Le coach et le gérant y ont accès tous les deux, avec des différences signalées ci-dessous.

## La barre latérale

1. Les écrans sont rangés par groupes : **Entraînement**, **Communauté**, **Animation**, **Pilotage**. Clique le titre d'un groupe pour le replier ou le déplier ; ton choix est gardé dans ce navigateur. Un groupe replié affiche quand même ses compteurs, par exemple les messages non lus.
2. Un coach voit seulement **Entraînement** (Whiteboard, Horaires, Créneaux types), **Animation** (Messages) et **Aide**. Le Dashboard, **Support**, **Réglages** et le badge d'abonnement AthleX sont réservés au gérant. <Screenshot src="/tutorials/barre-laterale-et-messages/1.png" alt="Barre latérale d'un coach : Entraînement, Animation, Aide, puis Mode clair, Mon espace athlète et Déconnexion" />
3. Tu gères ou encadres plusieurs box ? Un sélecteur apparaît sous le nom de la box. Choisis-en une autre : la page se recharge sur cette box. Il existe dès deux box, coach compris. <Screenshot src="/tutorials/barre-laterale-et-messages/2.png" alt="Sélecteur de box ouvert avec deux box, la box active cochée" />
4. En bas : **Mode clair** ou **Mode sombre** change le thème (retenu dans ce navigateur), **Mon espace athlète** ouvre ton compte d'athlète, **Déconnexion** te ramène à l'écran de connexion.

## Discuter dans un groupe

1. Ouvre **Messages** : la colonne **Conversations** liste les groupes de la box. Un coach n'y voit que les groupes dont il est membre.
2. Clique un groupe : le fil s'affiche par jour (« Aujourd'hui », « Hier », puis la date), tes messages à droite, ceux des autres à gauche avec leur pseudo et l'heure. Les nouveaux messages arrivent en direct. <Screenshot src="/tutorials/barre-laterale-et-messages/3.png" alt="Messages : colonne Conversations et fil du groupe Compétiteurs sur deux jours" />
3. Écris dans le champ « Message dans … » en bas, puis appuie sur Entrée ou clique le bouton d'envoi.

## Envoyer une annonce

1. En bas de la colonne **Conversations**, clique **Envoyer une annonce**. Depuis la fiche d'un groupe, le bouton **Message** ouvre la même page avec ce groupe déjà choisi.
2. Remplis la page « Envoyer un message » : **Type** (**Annonce**, **Rappel**, **Alerte**, **Info**), **Titre (optionnel)**, **Message \*** et **Groupe cible** (**Tous les membres** ou un groupe). <Screenshot src="/tutorials/barre-laterale-et-messages/4.png" alt="Page Envoyer un message avec le type Rappel et le groupe cible Compétiteurs" />
3. Clique **Envoyer** (grisé tant que le message est vide) : tu reviens sur **Messages**. **Annuler** abandonne.

<Callout type="warning">
Aujourd'hui, seul le gérant propriétaire de la box peut envoyer une annonce. Pour un coach ou un co-gérant, la base refuse l'envoi et un bandeau rouge s'affiche : passe par le fil de discussion du groupe.
</Callout>

## Erreurs fréquentes

- **Un coach ne voit pas un groupe.** Il n'en fait pas partie → le gérant l'ajoute au groupe dans **Groupes**.
- **« Aucun groupe ».** La box n'a pas encore de groupe → le gérant clique **Créer un groupe** ; pour un coach, ce lien mène à « Accès refusé ».
- **Ton message reste dans le champ.** L'envoi a échoué sans message d'erreur → recharge la page et réessaie.
- **Bandeau rouge sur « Envoyer un message ».** La base a refusé l'annonce (compte coach ou co-gérant, par exemple) → le texte du bandeau dit pourquoi.
- **« Message envoyé au back office mais erreur app: … ».** L'annonce est enregistrée mais pas diffusée dans l'app → ne la renvoie pas telle quelle, préviens tes membres autrement.
- **Le sélecteur de box n'apparaît pas.** Tu n'es gérant, co-gérant ou coach que d'une seule box.
