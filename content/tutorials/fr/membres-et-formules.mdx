## Avant de commencer

Les membres rejoignent la box avec le **code invitation** du Dashboard. La page **Membres** (Communauté → Membres) liste ensuite tout le monde, avec la recherche, les filtres et l'accès aux contrats.

## Étapes

1. Ouvre **Membres** : le compteur du haut indique le nombre de fiches affichées sur le total, et la recherche accepte un nom ou un e-mail. <Screenshot src="/tutorials/membres-et-formules/1.png" alt="Liste des membres avec la recherche et les filtres" />
2. Affine avec les filtres : par groupe, ou par état de contrat, pour retrouver par exemple les membres sans abonnement.
3. Clique **Contrats** pour afficher la colonne **Contrats / Abonnements** : tu vois d'un coup d'œil quelle formule chaque membre détient et jusqu'à quand.
4. Ouvre une fiche membre pour son détail : groupes, ELO, historique. C'est aussi d'ici que tu vérifies qu'un membre est bien actif.
5. Les formules elles-mêmes (prix, durée, engagement) se créent dans **Programmes athlètes** : la page Membres les consomme, elle ne les définit pas.

## Erreurs fréquentes

- **Un adhérent n'apparaît pas dans la liste.** Il n'a pas encore rejoint la box avec le code invitation → renvoie-lui le code depuis le Dashboard.
- **Un membre dit payer mais n'a aucun contrat.** Le paiement a été fait hors AthleX, ou la souscription n'a pas abouti → vérifie la colonne Contrats et, si besoin, donne-lui l'accès depuis Programmes athlètes.
- **Impossible de créer une formule depuis Membres.** C'est normal : la création et l'édition des formules vivent dans Programmes athlètes → ouvre cette page.
- **Un coach ne voit pas la page Membres.** Elle est réservée au gérant → connecte-toi avec le compte owner.
