## Avant de commencer

Tu viens de créer ta box : le Dashboard est la page d'accueil du back-office, et la barre latérale regroupe les rubriques par casquette (Entraînement, Communauté, Animation, Pilotage). Compte cinq minutes pour cette mise en route.

## Étapes

1. Ouvre le **Dashboard** : les compteurs du haut (**Tournois actifs**, **Membres**, **Scores en attente**, **Messages non lus**) sont des raccourcis, pas de simples chiffres : un clic ouvre la rubrique correspondante. <Screenshot src="/tutorials/premiers-pas/1.png" alt="Dashboard : les quatre compteurs de la box et le code d’invitation" />
2. Va dans **Réglages** et remplis les **Informations de la box** (nom, description, adresse, contact), puis ajoute ton **Logo de la box** et ta **Bannière de la box**. Ce sont les éléments que voient tes membres et les visiteurs de ta page publique. <Screenshot src="/tutorials/premiers-pas/2.png" alt="Haut du bloc Informations de la box dans les Réglages" />
3. Dans **Membres**, passe tes coachs en **Coach** depuis la colonne **Rôle** ; ils apparaissent ensuite dans **Réglages** → **Détails de la box**. Un coach voit le Whiteboard, les Horaires, les Créneaux types, les Messages et l'Aide ; il ne voit ni le Dashboard, ni les prix, ni les abonnés. <Screenshot src="/tutorials/premiers-pas/5.png" alt="Coachs listés dans Détails de la box, dans les Réglages" />
4. Récupère le **Code d'invitation box** depuis le Dashboard (bouton **Copier le code**) et transmets-le à tes adhérents : c'est par lui qu'ils rejoignent la box dans l'application athlète. <Screenshot src="/tutorials/premiers-pas/6.png" alt="Code d’invitation de la box sur le Dashboard" />
5. Crée tes premiers **Groupes** (Communauté → Groupes) si tu programmes différemment selon les créneaux ou les niveaux : ils servent ensuite à cibler les WODs. <Screenshot src="/tutorials/premiers-pas/7.png" alt="Page Groupes avec un groupe Semaine et un groupe Jour par jour" />
6. Choisis comment tes adhérents arrivent : essai depuis ta page publique, invitation nominative, abonnement en ligne ou code de la box. Les quatre parcours sont comparés dans « Les quatre façons d'entrer dans ta box », et le lien personnel avec formule préassignée dans « Inviter un membre nominativement ».

## Besoin d'aide ?

La barre latérale a une entrée **Support** : « Une question, un bug ou une idée pour AthleX Manager ? Contactez l'équipe AthleX. »

1. **Nouvelle demande**, puis choisis le type : **Question**, **Bug** ou **Idée d'amélioration**. <Screenshot src="/tutorials/premiers-pas/4.png" alt="Formulaire de nouvelle demande de support" />
2. Donne un **Titre de la demande** court et décris la demande : la page concernée, ce que tu as fait, ce que tu attendais, ce qui s'est passé, et le nom du membre ou de la formule en cause. C'est ce qui évite un aller-retour.
3. **Envoyer** crée le ticket avec le statut **Ouvert**. Il passe à **Répondu** quand l'équipe te répond, puis à **Résolu**. Clique **Marquer résolu** dans le ticket quand c'est réglé ; un ticket résolu ne se relance plus.
4. Un badge sur l'entrée **Support** signale les réponses non lues : rouvre le ticket pour lire l'échange et répondre dans le fil.

## Erreurs fréquentes

- **Un coach dit qu'il ne voit pas les Formules ni la Marketplace.** C'est volontaire : ces pages fixent des prix, elles sont réservées au gérant → passe par ton propre compte owner.
- **Un membre ne trouve pas la box dans l'app.** Le code d'invitation n'a pas été communiqué ou a été recopié à la main avec une erreur → renvoie-le depuis le Dashboard.
- **Le logo n'apparaît pas côté athlète.** L'image n'a pas été enregistrée dans Réglages, ou le téléversement a échoué → recharge la page et vérifie que l'aperçu du logo s'affiche.
