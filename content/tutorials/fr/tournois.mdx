## Avant de commencer

Les **Tournois** (Animation → Tournois) animent la box : une épreuve, des participants, un classement. La page sépare **En cours & à venir** de l'**Historique**.

## Étapes

1. Ouvre **Tournois** et clique **Créer un tournoi**. <Screenshot src="/tutorials/tournois/1.png" alt="Liste des tournois de la box" />
2. Renseigne le tournoi : nom, date, niveau et format. Le **Statut** affiché dans la liste suit ensuite le cycle de vie de l'épreuve.
3. Ouvre le tournoi créé pour gérer ses **Participants** : les membres de la box s'ajoutent depuis la fiche.
4. Le jour J, saisis les résultats depuis la fiche du tournoi : le **Classement** se recalcule au fur et à mesure.
5. Une fois terminé, le tournoi part dans l'**Historique** et les performances restent visibles pour les athlètes.

## Erreurs fréquentes

- **« Aucun tournoi. »** Rien n'a encore été créé dans cette box → clique Créer un tournoi.
- **Un membre ne peut pas être inscrit.** Il n'est pas membre actif de la box → vérifie sa fiche dans Membres.
- **Le classement semble figé.** Tous les résultats ne sont pas saisis → complète les scores manquants depuis la fiche du tournoi.
- **Un tournoi passé encombre la liste.** Il rejoint l'Historique quand il est terminé → change son statut plutôt que de le supprimer, pour garder les performances.
