## Before you start

The WOD editor has three areas: **Programme / Mouvements** (the metcon), **Musculation** (strength, optional) and **Cardio** (optional). Both optional blocks are written as sets, not as free reps.

## Steps

1. Open a WOD on the Whiteboard and find the **Musculation (optionnel)** block.
2. Click **Ajouter une série**, then fill in the exercise, sets, reps and load — in kilos, as **%1RM**, or as a free note such as `RPE 9` when the load depends on the day. A **Tempo** (`30X1`) and a rest value can complete the line. <Screenshot src="/tutorials/blocs-force-musculation-cardio/1.png" alt="Strength block with one set, load and tempo" />
3. Scroll to the **Cardio (optionnel)** block and click **Ajouter une série cardio**: pick the movement (Row, SkiErg, Run and so on), the number of sets and the quantity in metres or calories.
4. Add an intensity target if you want one: watts **or** pace, never both on the same line. Rest between sets is written as `mm:ss`.
5. Publish the WOD: the three blocks reach the athlete app together, in the order you wrote them.

## Common mistakes

- **Strength sets credit no badge.** That is the expected behaviour: sets in the strength block do not count badge reps, they are not metcon → put whatever must count in the metcon.
- **A cardio set is not credited.** The cardio block *is* credited, as `sets × quantity`, but only when the movement comes from the catalogue → pick Row, SkiErg, Run and so on from the list.
- **A pace target is ignored.** Both watts and a pace were entered on the same line → keep only one of them.
- **An "RPE 9" load disappears from the kilos field.** A non-numeric load is not a weight: it belongs in the load note → use the free note field.
