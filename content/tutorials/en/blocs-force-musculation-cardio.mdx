## Before you start

The WOD editor has three areas: **Programme / Mouvements** (the metcon), **Musculation** (strength, optional) and **Cardio** (optional). Both optional blocks are written as sets, not as free reps.

## Steps

1. Open a WOD on the Whiteboard and find the **Musculation (optionnel)** block. <Screenshot src="/tutorials/blocs-force-musculation-cardio/3.png" alt="Musculation, Cardio and Time cap blocks of the WOD form" />
2. Click **Ajouter une série**, then fill in the exercise, sets, reps and the **Charge** in **kg** or **%1RM**; when the load depends on the day, write it in **Charge libre** (`RPE 9`). A **Tempo** (`30X1`) and a rest value in seconds can complete the line. <Screenshot src="/tutorials/blocs-force-musculation-cardio/1.png" alt="Strength block with one set, load and tempo" />
3. Scroll to the **Cardio (optionnel)** block and click **Ajouter une série cardio**: pick the movement (Row, SkiErg, Run and so on), the number of sets and the quantity in metres, calories or seconds. <Screenshot src="/tutorials/blocs-force-musculation-cardio/2.png" alt="Cardio (optional) block with a Row set" />
4. Add an intensity target if you want one: watts **or** pace, never both on the same line. Rest between sets is written as `mm:ss`, and an **RPE** can complete the line. <Screenshot src="/tutorials/blocs-force-musculation-cardio/4.png" alt="Cardio line with watts, target, rest and RPE" />
5. Click **Créer le WOD** (or **Enregistrer**): the three blocks reach the athlete app together, always in this order: Musculation, Cardio, then the metcon.

## Common mistakes

- **Strength sets credit no badge.** That is the expected behaviour: sets in the strength block do not count badge reps, they are not metcon → put whatever must count in the metcon.
- **A cardio set is not credited.** The cardio block *is* credited, as `sets × quantity`, but a line without an exercise is not saved ("Choisis l’exercice pour enregistrer cette série.") → pick Row, SkiErg, Run and so on from the list.
- **A pace target is ignored.** It is not in `mm:ss` format → write it like `2:00`, then pick `/500 m` or `/km`.
- **An "RPE 9" load does not fit in the Charge field.** That field only takes numbers → write it in **Charge libre**.
