## Before you start

Members join the box with the invitation code from the Dashboard. The **Membres** page then lists everybody, with search, filters and access to contracts.

## Steps

1. Open **Membres**: the counter at the top shows how many records are displayed out of the total, and the search accepts a name or an email. <Screenshot src="/tutorials/membres-et-formules/1.png" alt="Member list with search and filters" />
2. Narrow it down with the filters: by group, or by contract state, to find for instance members without a subscription.
3. Click **Contrats** to show the **Contrats / Abonnements** column: you see at a glance which plan each member holds and until when.
4. Open a member record for the detail: groups, ELO, history. This is also where you check that a member is active.
5. The plans themselves (price, duration, commitment) are created in the athlete programs page: the member list consumes them, it does not define them.

## Common mistakes

- **A member is missing from the list.** They have not joined the box with the invitation code yet → send them the code from the Dashboard.
- **A member says they paid but has no contract.** The payment happened outside AthleX, or the checkout never completed → check the contracts column and, if needed, grant access from the athlete programs page.
- **You cannot create a plan from the member list.** That is expected: creating and editing plans lives in the athlete programs page → open it there.
- **A coach cannot see the member list.** It is owner-only → sign in with the owner account.
