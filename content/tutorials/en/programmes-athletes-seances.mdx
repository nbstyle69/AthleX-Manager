## Before you start

An athlete program is a follow-up sold or granted to a member: it holds sessions organised by week, independent from the box Whiteboard. The page is **Marketplace → Programmes athlètes** (`/programming/athletes`), the third Marketplace tab.

## Steps

1. Open **Marketplace → Programmes athlètes** and find the card of the program to fill in (or create it first, see the selling tutorial). <Screenshot src="/tutorials/programmes-athletes-seances/1.png" alt="Session editor of a program: week 1 / 8, day columns, two rest days" />
2. Click **Séances** on its card: the editor shows « Semaine 1 / X », X being the **Durée (semaines)** of a fixed program; an Ongoing program has no last week.
3. Pick the week with the arrows, then click **Ajouter** in the day column (or **Nouvelle séance**) and write the content like a WOD: **Programme / Mouvements** (catalogue), **Musculation**, **Cardio**, **Notes Coach**. A day marked **Repos** (moon icon) takes no session.
4. You can start from a file: **Importer** accepts a PDF (the import proposes the detected sessions and you review the preview before inserting), a CSV or a JSON (template: **Modèle CSV**).
5. Each session is saved with **Créer la séance**. The athlete who has access to the program receives it from their own start date: week 1 is their first week. An unpublished session (crossed-out eye) stays invisible to them.

## Common mistakes

- **The athlete sees no session.** The program has no published session, or access was never granted → check both; access is granted with the **Accès** button on the program card.
- **Movements credit no badge.** They were typed by hand instead of picked from the official list → edit the lines concerned.
- **A week is unreachable.** The program duration is shorter than the number of weeks you want to write → increase the **Durée (semaines)** with **Modifier** on the program card.
- **Program sessions end up on the Whiteboard.** These are two separate spaces: an athlete program is never placed on the box Whiteboard → use a week template if you want to program it for everybody.
