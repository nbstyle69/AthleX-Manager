## Before you start

An athlete program is a follow-up sold or granted to a member: it holds sessions organised by week, independent from the box Whiteboard. The page is **Marketplace → Programmes athlètes** (`/programming/athletes`), the third Marketplace tab.

## Steps

1. Open **Marketplace → Programmes athlètes** and select the program to fill in (or create it first, see the selling tutorial).
2. Open its session editor: weeks are numbered according to the program duration in weeks. <Screenshot src="/tutorials/programmes-athletes-seances/1.png" alt="Session editor of an athlete program" />
3. Add a session to the week you want, then write its content like a WOD: catalogue movements, strength block, cardio block, coach notes.
4. You can start from a PDF: the import proposes the detected sessions and you review the preview before inserting.
5. Save. The athlete who has access to the program sees the sessions in their logbook, week by week.

## Common mistakes

- **The athlete sees no session.** The program has no saved sessions, or access was never granted → check both; access is granted from **Marketplace → Programmes athlètes**.
- **Movements credit no badge.** They were typed by hand instead of picked from the official list → edit the lines concerned.
- **A week is unreachable.** The program duration is shorter than the number of weeks you want to write → increase the duration in weeks.
- **Program sessions end up on the Whiteboard.** These are two separate spaces: an athlete program is never placed on the box Whiteboard → use a week template if you want to program it for everybody.
